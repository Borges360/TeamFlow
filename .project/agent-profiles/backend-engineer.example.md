# EXAMPLE CONTEXT — Backend Engineer profile

> Replace with real standards, supported versions, repository patterns, and owners.

Extends the universal Software Engineer responsibility for repositories cataloged with Java, Go, Python, DynamoDB, or PostgreSQL.

## Example focus

- API/event/data compatibility and consumer impact;
- transactions, concurrency, idempotency, timeouts, retries, and failure semantics;
- DynamoDB key/access patterns, conditional writes, capacity and indexes;
- PostgreSQL schema/query/migration/locking behavior;
- authentication/authorization, data minimization, logs/metrics/traces;
- unit, component, contract/API, integration, regression, security, and performance evidence according to risk.

Use repository-local build/test instructions. Do not assume one backend language or datastore merely because the squad supports it.
