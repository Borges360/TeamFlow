# EXAMPLE CONTEXT — Skill: SRE/DevOps Change

> Replace tools, accounts, environments, commands, policies and authorities.

1. Establish affected resources, state/config owners and approved environment.
2. Generate and inspect Terraform plan or CloudFormation change set; assess replacement/destruction, dependencies, IAM/network/encryption, drift, tags and cost.
3. Validate syntax, policy and infrastructure behavior using approved checks.
4. Define staged apply/deploy, stop conditions, rollback and post-change validation.
5. Update Datadog telemetry/alerts/SLO artifacts only with owner, runbook and actionability.
6. Retain plan, checks, approvals and observed results without secrets.
