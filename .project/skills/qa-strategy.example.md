# EXAMPLE CONTEXT — Skill: Cross-Platform QA Strategy

> Replace test tooling, environments, standards and thresholds.

1. Convert acceptance criteria and architectural risks into test conditions.
2. Select relevant layers across backend, frontend/webview, data, infrastructure, mainframe, accessibility, security and operations.
3. Define environments, test data, oracles, evidence and owner before execution.
4. Use Robot Framework only where it is the approved fit; use repository-native tools elsewhere.
5. Execute risk-based regression and retain structured results plus defects.
6. Report coverage gaps, flakes, skips, blocked tests and residual risk explicitly.
