# Skill: Incident Analysis

## Purpose

Build an evidence-based incident timeline and causal analysis without blame.

## Procedure

1. Normalize events into one timezone while preserving source timestamps.
2. For every action, record actor, hypothesis, evidence, change, result, and rollback state.
3. Separate trigger, contributing conditions, detection/control gaps, and impact amplifiers.
4. Validate recovery with business and system signals across an observation window.
5. Write causal statements that connect conditions to outcomes; avoid “human error” as a root cause.
6. Create outcome-based follow-ups with owners, priority, due dates, and validation method.

## Output

Incident timeline/postmortem, retained evidence, and owned corrective actions.
