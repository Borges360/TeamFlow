# Skill: Performance Analysis

## Purpose

Produce a representative, reproducible performance finding.

## Procedure

1. Define user/business journey, target, baseline, workload distribution, data size, concurrency, and environment.
2. Verify instrumentation and clock/measurement quality.
3. Warm up or explicitly measure cold behavior; document caches and limits.
4. Run repeated experiments and retain client, service, dependency, infrastructure, and cost signals.
5. Locate saturation and bottlenecks; distinguish correlation from cause.
6. Compare with baseline/target and state uncertainty and extrapolation limits.

## Output

Performance review with procedures, raw result references, analysis, regressions, capacity implications, and prioritized recommendations.
