# Skill: Architecture Decision

## Purpose

Make a consequential design decision explicit, comparable, and reviewable.

## Procedure

1. Phrase the decision question and name the owner and deadline.
2. Record context, constraints, quality-attribute scenarios, and reversibility.
3. Identify at least two credible options when alternatives exist, including the status quo.
4. Compare functional fit, compatibility, security, resilience, data, operations, performance, cost, migration, and exit strategy according to applicability.
5. Select an option, document consequences and unknowns, and request specialist review.
6. Create an ADR; use diagrams only for relationships that prose cannot express clearly.

## Output

An ADR with evidence-backed rationale and actionable consequences.
